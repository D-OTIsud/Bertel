## Decisions

The source adapter in `supabase/migrations/20261106112948_thesaurus_publication.sql` covers ref_code, amenity, classification scheme/value, language, commune, sustainability category/action. Consumer snapshot reads additional references but does not establish editorial authority.

Nine new node adapters are in the approved next-work scope: six public-eligible semantic dictionaries and three PRIVATE business relationship-role dictionaries (no visibility widening). The six public-eligible dictionaries need four-language content. `ref_iti_assoc_role` (8), `ref_object_relation_type` (10), `ref_capacity_metric` (12), `ref_legal_type` (21), `ref_review_source` (7), `ref_sustainability_action_group` (76). The first five have UUID PKs, code/name/description-style fields and public SELECT policies, but no native i18n. Review source is provenance-oriented, requiring owner confirmation. Group has native name_i18n/description_i18n and a category FK; actions point to group_id while scheme/group equivalence is a separate edge. None is writer-ready: absent from thesaurus.source_rows and publication guard. Do not change existing visibility flags/legacy allowlists.

`ref_tag` is classified as application free-tag entities: 46 rows, 4,626 tag_link rows, 44 used, 2 unused, creator present on 29 and absent on 17. Preserve the native tag writer; do not assume controlled-concept curation. Permission, admin-role, business-role remain private authorization metadata. Actor, contact and organization relationship roles are descriptive business-role lookup candidates (FKs to actor-object roles, channel roles and object-org links), distinct from user_org_admin_role/user_org_business_role authorization and permission enforcement. Treat their node identities as unadapted; keep publication scope private until domain/security owners authorize. Documents are mixed-scope entities; public row policy is access-scope restricted, but no content is copied. Other gaps are entity refs, relation/applicability/crosswalk edges, derived closure or system registries.

The 26 formerly unmapped keys now resolve to 9 planned node adapters (6 public-eligible + 3 private, 148 identities) and 17 deliberately non-adapter entity/relation/system/free-tag catalogs. Implementation remains separate from this audit.

Group codes are unique globally and within category in the capture. The 239 group-membership edges are distinct from 761 category-parent edges and are not represented in the current thesaurus parent relation. Exact repeatable query (counts only):

```sql
SELECT
  count(*) FILTER (WHERE a.group_id IS NOT NULL) AS actions_with_group,
  count(*) FILTER (WHERE a.group_id IS NOT NULL AND a.category_id=g.category_id) AS category_consistent,
  count(*) FILTER (WHERE a.group_id IS NOT NULL AND a.category_id<>g.category_id) AS category_mismatch
FROM public.ref_sustainability_action a
LEFT JOIN public.ref_sustainability_action_group g ON g.id=a.group_id;
SELECT count(*) FROM (
  SELECT code FROM public.ref_sustainability_action_group GROUP BY code HAVING count(*)>1
) d;
SELECT count(*) FROM (
  SELECT category_id,code FROM public.ref_sustainability_action_group GROUP BY category_id,code HAVING count(*)>1
) d;
```
